# Documentación del uso de inteligencia artificial --- Entrega 2

## 1. Apoyo en la elaboración y revisión del diagrama EER

**Consulta realizada a la IA:**\
Debido al manejo limitado del lenguaje Mermaid, se proporcionaron, una
por una, las modificaciones y los cambios específicos que debían
realizarse. Además, se solicitó apoyo para elaborar el diagrama EER,
teniendo en cuenta que se habían efectuado cambios importantes en la
estructura y en las reglas del negocio.

**Respuesta de la IA:**\
La IA proporcionó el código del diagrama EER en lenguaje Mermaid, con el
propósito de facilitar su verificación y la corrección de pequeños
errores.

**Uso dado a la respuesta:**\
El código proporcionado se llevó al editor web de Mermaid para comprobar
su funcionamiento e identificar posibles fallas o inconsistencias.
También se revisó que la representación fuera coherente con la
naturaleza del negocio y con los cambios realizados en su estructura y
reglas.

## 2. Ejemplo de referencia para el desarrollo de migraciones

**Consulta realizada a la IA:**\
Se solicitó un ejemplo completo de migración, correspondiente a un caso
diferente al del negocio, utilizado única y exclusivamente como guía
para desarrollar las demás migraciones requeridas.

**Respuesta de la IA:**\
La IA entregó un ejemplo completo que ilustraba el uso de DDL, DML y
DQL, así como la implementación de claves primarias, claves foráneas y
otros elementos habituales en la definición y manipulación de una base
de datos.

**Uso dado a la respuesta:**\
El ejemplo se utilizó como material de consulta para orientar el
desarrollo de las migraciones correspondientes al negocio **Banco Cierra
Nevada**. Se tomó como referencia para comprender la estructura y la
aplicación de las instrucciones SQL, no como una migración lista para
incorporarse directamente a la entrega.

## 3. Generación de datos ficticios para las tablas

**Consulta realizada a la IA:**\
Se compartieron capturas de la estructura de objetos y tablas ---por
ejemplo, la tabla `Sucursal`--- con sus respectivas columnas. Se
solicitó generar cantidades de datos aleatorios y ficticios para los
diferentes campos.

**Respuesta de la IA:**\
La IA generó distintos conjuntos de datos inventados, como direcciones,
edades, fechas, nombres y otros valores adecuados al tipo de cada
columna.

**Uso dado a la respuesta:**\
Se seleccionó una cantidad de datos para cada tabla con el objetivo de
que las consultas solicitadas en la entrega produjeran resultados
coherentes y útiles para su comprobación. Los valores generados se
revisaron y, cuando fue necesario, se modificaron o sustituyeron por
`NULL` u otros datos ficticios, según las necesidades de cada caso.
Estas decisiones se tomaron para mantener la consistencia de la
información y facilitar la validación de las consultas.

## 4. Otros usos de la inteligencia artificial

Además de los usos descritos, la IA se utilizó como herramienta de apoyo
en otras tareas relacionadas con la entrega 2, entre ellas:

-   Orientación para documentar los archivos correspondientes a la
    entrega.
-   Aclaración de conceptos y resolución de dudas puntuales.
-   Recomendaciones sobre políticas y prácticas para preservar la
    integridad de la base de datos.
-   Orientación sobre la aplicación de restricciones y reglas de
    negocio.
-   Apoyo para revisar ideas y comprender alternativas de
    implementación.

Estas respuestas se utilizaron como orientación y se evaluaron de
acuerdo con los requisitos del trabajo y las decisiones del equipo.

## 5. Alcance y responsabilidad del uso de la IA

La inteligencia artificial **no se utilizó para crear de manera íntegra
ningún componente directamente relacionado con la entrega 2**. Su
función fue servir como guía, apoyo y herramienta de consulta durante el
proceso de desarrollo. Las propuestas generadas se revisaron y adaptaron
según las necesidades del negocio, la estructura de la base de datos y
las reglas establecidas para el proyecto.

Este apoyo también respondió a las condiciones de trabajo del equipo,
conformado por dos integrantes activos, que debieron distribuir y
atender las distintas tareas de la entrega procurando desarrollarlas con
el mayor cuidado posible. En consecuencia, la IA se empleó para
facilitar la comprensión de algunos temas, orientar tareas específicas y
apoyar la revisión, sin sustituir el análisis ni las decisiones del
equipo.
